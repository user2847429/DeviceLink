# Security policy

DeviceLink is intended to carry private data between devices on a local network.
Security reports are welcome.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private
vulnerability reporting for this repository if it is enabled. Otherwise, contact
the maintainers privately through GitHub to arrange a responsible disclosure.

Include affected commit/version, platform, reproduction steps, and impact. Do not
send real private keys, passwords, message contents, or other personal data.

## Current security status

The transport, pairing, identity, and permission model are **not implemented yet**.
Do not use this scaffold to transfer sensitive data. The project will not claim
production security until the protocol and its implementation have been reviewed
and tested.
